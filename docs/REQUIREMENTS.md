## M1 生成参数系统（Generation Profile）— ✅ 批次一

用户可调参数，存 `WorldState.genProfile`，写作/审查/抽卡全部读取。

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| 章节字数范围 | 300-500 | 100-20000 | 导演写作的目标字数（writer 提示词注入） |
| 遵循设定模式 | 架空 | 历史真实/架空/混合 | 历史真实 → 写作前 AnySearch 考据注入；架空 → 纯虚构；混合 → 关键节点考据 |
| 文风基调 | （跟随立项） | 自由文本 | 覆盖 setting.tone，注入写作提示 |
| 叙述视角 | 第三人称 | 第一/第二/第三人称 | 注入写作提示 |
| 模型温度 | 0.9 | 0-2 | 传给 Agnes |
| 审查严格度 | 标准 | 宽松/标准/严格 | 宽松：地板 4、重写 1 次；标准：地板 6、重写 2 次；严格：地板 7、重写 3 次 |
| 每节新伏笔上限 | 2 | 0-4 | 传给导演 |
| 强制章节结尾钩子 | 开 | 开/关 | writer 提示词 |
| 自动抽卡 | 关 | 开/关 | 每节推进前自动抽 1 张（autoPick） |
| 模型选择 | 由 `.env` `TEXT_MODEL` 控制（当前基元 deepseek-v4-flash-0731，可整体切换） | 任意 OpenAI 兼容模型 | 文本模型端点级配置，非 GenProfile 参数 |

验收：参数面板可编辑并保存；改字数/视角/严格度后下一节实测生效。

## M2 抽卡系统升级（四类卡池）— ✅ 批次一

按用户要求，卡池针对四个方向 + 保留原类型：

| 卡池 | 内容 | 注入方式 |
|---|---|---|
| 发展方向卡 | 剧情走向：转折/危机/支线/高潮/结局推进 | 注入下一节写作指令（大纲方向） |
| 角色卡 | 新角色：身份/性格/与主角关系/登场时机 | 注入指令 + 登记"待登场角色" |
| 伏笔卡 | 悬念：内容 + 建议回收章节区间 | 直接入伏笔账本（planted） |
| 章节卡 | 本节推进：场景/节拍/视角切换/关键对话 | 注入本节指令 |
| 道具/场景卡（保留） | 关键物品/新地点 | 注入指令 + 登记 |

参数：卡池数量（1-6，默认 4）、自动抽取开关与张数、稀有度权重、抽卡历史去重（已有）。

验收：四类卡池可分别生成；抽中后注入位置正确；伏笔卡入账。

## M3 世界书/设定库（Lorebook）— ✅ 批次二

SillyTavern 式条目化设定：

- 条目 `{ id, keywords[], content, enabled }`：写作时按关键词匹配注入（最多 N 条）
- 自动生成：从世界状态生成人物/地点/规则/势力/术语条目
- 手动增删改（面板）
- 注入可见性：写作时触发哪些条目 → 返回 `used_lore` 展示
- 考据模式：历史真实 → 自动 AnySearch 查证（朝代/官职/地理/风俗），结果入条目

验收：条目可管理；写作上下文含触发条目；历史真实模式自动考据。

## M4 记忆强化（弧线 + 声线 + 分层摘要）— ✅

| 模块 | 说明 |
|---|---|
| 情节弧线追踪 | `arcs: { id, name, status: 进行中/已解决, 涉及人物, 最近进展 }`，每章由导演输出更新；writer/critic 上下文注入；面板可视化 |
| 角色声线档案 | 角色 `voice: 说话风格` 字段；对话生成提示注入 |
| 分层摘要 | 即时记忆（上节结尾）+ 工作记忆（最近 3 节摘要）+ 长期记忆（弧线/关键事实）——压缩注入 |

验收：弧线随章节推进更新；声线注入对话；长文（≥10 章）不丢失关键事实。

## M5 审查体系升级 — ✅ 批次一/二

- 严格度参数驱动（M1）：地板阈值 + 重写轮数
- 审查维度扩展：连续性/伏笔/逻辑/文笔/节奏/对话 + **弧线推进检查**（该推进的弧线是否推进）
- 审查报告含弧线状态更新建议（自动应用开关）

验收：严格度切换后行为变化；弧线检查生效。

## M6 章节编辑器升级 — ✅（版本回滚/单章重生成）批次三

- 单章重生成（保留伏笔/弧线链，替换文本 + 重新审查）
- 字数统计/目标显示（对比 M1 目标字数）
- 导出 Markdown（已有）/ EPUB（后续）

验收：重生成不破坏后续连续性；字数达标提示。

## M7 界面（控制面板完备化）— ✅ 批次一/二/三

- 左栏新增标签：生成参数（M1 表单）/ 世界书（M3 条目管理）/ 弧线（M4 面板）—— *已演进：配置类统一并入 ⚙ 设置弹层（全局/章节/设定/角色/大纲/导出 6 Tab，章节/设定/角色左右两列），左栏收敛为 目录/规划/脉络 3 标签；右栏状态面板按当前章节只读展示人物（被提及或出场，LLM 语义判定）与伏笔账（本章埋设/触发）*
