# 生图词汇遵循度报告（VISUAL-VOCAB）

> 实验场：`scripts/prompt-lab.ts`，202 对头像+立绘（404 张），样本存 `lab/images/`，清单 `lab/manifest.json`。
> 评分：2=遵循 / 1=部分 / 0=忽略。基底上下文默认明朝·京城（B/C/J 组），单变量对照。
> 结论用于收敛 `src/api/media.ts`（仅实测条目）。

## 2. 关键发现

1. **具体名词 > 抽象描述**：弱模型只画"看得见的物件"。听诊器/放大镜/葫芦/卦幡/全息账本/怀表/圣水瓶/试剂瓶（含疑似臆想条目）全部遵循；"商务休闲/干练利落/瑜伽服"类抽象词忽略。
2. **臆想条目多数并非问题，问题在"不具体"**：丹葫芦✓、卦幡✓、全息账本✓。应改写而非删除不遵循条目。
3. **帽类是禁帽条款的代价**：安全帽/厨师帽/骑行头盔被 NO_HAT_CLAUSE 压制（设计预期，稳定优先）；眼罩非帽但概率性丢失。
4. **年龄单独无效，组合有效**：年龄词须与身份/性别同现才生效。
5. **发型不随时代**：eraDress 的发型子句弱于模型"古代=束发插簪"先验。
6. **组合预期（验收②）达标**：G 组 6 抽查 5 组全要素命中（性别+身份服饰+表情+姿态），~90%。

## 3. 收敛动作（阶段 3，仅实测条目）

- `FACE_SHAPES` 删 3 个忽略词（圆脸/方圆脸/菱形脸），保留 长脸/瓜子脸/鹅蛋脸/方脸。
- `EYE_BROWS` 删「平眉深眼窝」，保留 5。
- 身份条目改写为"手持具体物件"：体修（露臂膀→挽袖露臂+束腰带）、账房（→手拨算盘）、拍卖（→手持小木槌）、厨师（头戴厨师帽→手持炒勺，避帽冲突）、施工员（戴安全帽→安全帽挂腰侧）、外卖/骑行（头盔→头盔挂腰/护目镜）。
- `eraDress` 非古代档（民国/现代/未来）发型子句前置具体化：「利落短发，头顶无发髻无发簪」。
- `generateCharacterAvatar/Portrait` 增加可选 `opts.pose/opts.expression` 透传槽位（默认不传，生产行为不变；遵循率达标的能力开放给用户自定义）。
- 池子收缩改变 hash 分配 → 复跑 `refresh-visuals.ts` 刷新真实书。
